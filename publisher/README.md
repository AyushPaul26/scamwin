# Isolated Scamwin publisher

Create a separate Vercel project from this repository with **Root Directory `publisher`**, **Framework Preset Other**, Node **24.x**, and **Include source files outside of the Root Directory in the Build Step enabled**. Keep the committed `vercel.json` settings: `npm ci`, `npm run build`, output `public`, Fluid Compute, and a 300 second maximum invocation. The native Node function is `/api/relay`; no Next application or investigation browser is included.

Set these only as project scoped **Production** secrets: `DATABASE_URL`, `SCAMWIN_PUBLISHER_PRIVATE_KEY`, `SCAMWIN_PUBLISHER_DISPATCH_SECRET`, `CRON_SECRET`, `SCAMWIN_REGISTRY_ADDRESS`, `SCAMWIN_REGISTRY_PUBLISHER`, `SCAMWIN_REGISTRY_CHAIN_ID=84532`, and optionally `BASE_SEPOLIA_RPC_URL`. Use independent cryptographically random dispatch and cron secrets of at least 32 bytes. Never put the signing key in Preview, the main website or shared team variables. Environment configuration alone does not approve transactions; activate only after the deployment and fee caps have been explicitly approved.

The main website receives only `SCAMWIN_PUBLISHER_BASE_URL=https://your-publisher-project.vercel.app` (origin only, no path) and the dispatch secret. It appends `/api/relay`. POST uses `Authorization: Bearer <SCAMWIN_PUBLISHER_DISPATCH_SECRET>`. Daily cron GET uses `Authorization: Bearer <CRON_SECRET>`; Vercel supplies that header. Other methods return 405. Auth finishes before either database or signer modules load. Body and query are ignored. Each request asks the database for one pending reviewed operation, then reuses the existing publication relay with its consent, lease, nonce, chain, destination, zero value and fee guards. Submitted/included/safe statuses do not assert finality.

`npm ci && npm run build` prepares exactly eight reviewed pure Node modules from `../lib/scamwin` in ignored `lib/`, adding the explicit `.js` relative import extensions required by native Node ESM, then type checks with NodeNext resolution. It reads no dotenv files and copies no credentials. `npm run check:runtime` emits JavaScript, loads it with plain Node, verifies unauthenticated HTTP returns 401, and resolves the relay/store import closure without provider calls or signing. Commit the source and lockfile; generated `lib/` is built on Vercel. Keep source outside root enabled so that build can read the reviewed files. Do not import this publisher into the main website.

The injectable `createPublisherHandler({env, load})` in `handler.ts` accepts Web Requests and returns Web Responses. Its dependency loader runs only after successful auth. The native function is the default `{fetch}` export in `api/relay.ts`. Focused offline tests run from the repository root with `node --import tsx --test tests/scamwin-publisher-http.test.ts`.

Runtime references: [Vercel native Node handlers](https://vercel.com/docs/functions/runtimes/node-js), [cron authorization](https://vercel.com/docs/cron-jobs/manage-cron-jobs).
